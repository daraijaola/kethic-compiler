# Premium Showcase Targets V1

Status: Micheal-owned visual and benchmark direction.

Purpose: define what Kethic must prove before it is ready to power Clovoc's public AI-builder story.

The goal is not to make one pretty screenshot. The goal is to show that compact Kethic source can produce multiple high-quality website types.

## Target 1: AI Builder Landing Page

Audience: founders and builders comparing Clovoc, Lovable, v0, Replit, and similar tools.

Page sections:

- navbar
- hero
- feature grid
- showcase
- metrics
- workflow
- CTA
- footer

Visual direction:

- clean technical grid
- premium off-white background
- black typography
- lime accent
- compiler/product visual
- restrained motion

Proof needed:

- source is compact
- output is normal HTML/CSS/JS
- public benchmark says around 90% lower generated output

## Benchmark Rules

For each showcase, record:

- Kethic source characters
- baseline React/Tailwind source characters
- Kethic estimated completion tokens
- baseline estimated completion tokens
- reduction percentage
- generated output size
- desktop screenshot
- mobile screenshot

Public language:

- use `around 90% lower generated output` for broad claims;
- use exact values only when showing a specific recorded benchmark.

## First Showcase To Build

Start with Target 1: AI Builder Landing Page.

Reason:

- it connects directly to Clovoc;
- it proves the business story;
- it exercises the most important premium macros;
- it gives investors and users an immediate reason to care.
